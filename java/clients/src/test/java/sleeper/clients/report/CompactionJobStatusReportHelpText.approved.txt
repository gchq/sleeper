Usage: <instance-id> <table-name>
Available options: --help, --all, --detailed, --end-time, --format, --recent, --start-time, --unfinished

A report on compaction jobs within a Sleeper instance.

The jobs to report on are chosen with one of the query type options. Only one may be set at a time. If none is set, you will be prompted to choose one.

When run with compactionJobStatusReport.sh, the following options are passed to the JVM rather than the report:

--jvm-memory <size>: The maximum memory for the JVM, e.g. 512m or 8g. If this is more than the memory currently available, you will be asked to confirm before the report runs. If it uses more memory than is available, the report may run slowly or be killed by the operating system. If the report needs more memory than this, it will stop with an OutOfMemoryError.

--force-memory: Skips the confirmation prompt for --jvm-memory.

Below are the options for the report:

--all, -a
Reports on all jobs.

--detailed, -d <job-id>[,<more-ids>]
Reports in detail on the jobs with the given IDs. Separate several IDs with commas.

--end-time <yyyyMMddHHmmss>
End of the period to report on, in the format yyyyMMddHHmmss.
Can be combined with --start-time. Defaults to the current time.

--format <format>
Output format. One of JSON, STANDARD. Defaults to STANDARD.

--recent, -r
Reports on all jobs in the last 4 hours.

--start-time <yyyyMMddHHmmss>
Start of the period to report on, in the format yyyyMMddHHmmss.
Can be combined with --end-time. Defaults to 4 hours before --end-time, or 4 hours before the current time if --end-time is not set.

--unfinished, -u
Reports on all unfinished jobs.
